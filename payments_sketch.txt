PROBLEMS
1. StatCard width fixed to 120px (non-compact). Label is UPPERCASE and ellipsizes. Padding + icon + spacing leave little room for full text like 'PAID THIS MONTH'. Also FittedBox only affects value, not label. 
2. PageHeader actions: in wide layout we return Row with mark + Expanded(heading) + buttons. That should push buttons to far right. But 620px breakpoint drops them below; maybe user wants them always at far right unless very cramped? Or the Expanded on heading is correct but maybe on some widths it looks centered. Alternatively give heading min width or just ensure mainAxisAlignment spaceBetween? Or use Spacer() after heading instead of Expanded in a way that competes.
